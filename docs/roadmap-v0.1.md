# Roadmap V0.1

Foundation: define crops, producers, decisions, field constraints and trusted data sources.

Architecture: define context, observation, recommendation and provenance models.

MVP: deliver an explainable agronomic assistant grounded in documented sources.

Validation: test representative agricultural scenarios with domain experts and measure recommendation usefulness and error modes.

Release: complete safety, data-quality, QA, documentation and limitations review before V0.1.
