# Contribuer à AgroAI

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Les données agricoles doivent être contextualisées et obtenues légalement. Les recommandations sont expérimentales tant qu'elles ne sont pas validées sur le terrain. Afficher l'incertitude et éviter les conseils à haut risque sans expertise.

Une PR documente données, méthode, validation terrain, limites et impact.
